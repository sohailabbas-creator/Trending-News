About Rotate PDF

Some viewers rotate a page only for the current display; a PDF editor can save the orientation in the document. Reopen the output to confirm that the change persists.

Steps for Rotate PDF

  1. Select the PDF and note the page numbers that need rotation.
  2. Enter those page numbers, or leave the field empty to rotate all pages.
  3. Choose Rotate pages to turn the selected pages clockwise by 90 degrees.
  4. Download the new copy and reopen it to check the orientation.

Review the result

Do not rotate every page unless the full document is incorrectly oriented. Check neighboring pages to ensure a page-specific adjustment did not affect others.

Frequently asked questions

Why does a page look rotated only in my viewer?

The viewer may have applied a temporary display rotation that is not saved in the PDF. Reopen the file in another viewer to confirm its stored orientation.

Can I rotate only one page?

Many editors support page-specific rotation. Select the intended page and inspect the saved file afterward.
