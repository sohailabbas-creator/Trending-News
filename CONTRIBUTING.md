# Contributing to Trending News

Thank you for your interest in contributing to the Trending News project! This document provides guidelines and instructions for contributing.

## Code of Conduct

Please be respectful and professional when contributing to this project. All contributors are expected to be welcoming and supportive.

## Getting Started

1. **Fork the repository** on GitHub
2. **Clone your fork** locally
   ```bash
   git clone https://github.com/YOUR-USERNAME/Trending-News.git
   cd Trending-News
   ```
3. **Create a branch** for your feature or fix
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Making Changes

### Best Practices
- Write meaningful commit messages
- Keep commits focused on a single change
- Test your changes before submitting a PR
- Ensure code follows project conventions
- Add comments for complex logic

### Code Style

#### HTML
- Use semantic HTML5 tags
- Maintain proper indentation (2 spaces)
- Close all tags properly
- Use descriptive class and ID names

#### CSS
- Follow BEM (Block Element Modifier) naming convention
- Use consistent indentation (2 spaces)
- Group related properties together
- Use meaningful variable names
- Add comments for non-obvious styles

#### JavaScript
- Use const/let instead of var
- Follow camelCase for variable and function names
- Add comments for complex logic
- Use descriptive variable names
- Handle errors appropriately

## Submitting Changes

1. **Push your changes** to your fork
   ```bash
   git push origin feature/your-feature-name
   ```

2. **Create a Pull Request** with a clear description of:
   - What changes were made
   - Why the changes were made
   - Any related issues or PR numbers

3. **Respond to feedback** and make any requested changes

## Reporting Issues

If you find a bug or have a suggestion:

1. Check if the issue already exists
2. Provide a clear description
3. Include steps to reproduce (for bugs)
4. Include screenshots if applicable
5. Mention your browser and OS

## Questions?

Feel free to open an issue for any questions about the contributing process.

Thank you for helping improve Trending News! 🚀
