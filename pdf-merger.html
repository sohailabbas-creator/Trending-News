    What the PDF Merger does

    Merging PDFs is normally done by uploading your files to a server, waiting, and downloading the result. For a bank statement, a passport scan or a medical letter, that means a copy of a sensitive document sits on someone else's infrastructure, and the free tiers usually come with page limits.

    This merger runs entirely in your browser using a local PDF engine. Your files are read from disk into memory, combined in the order you set, and offered back as a download. Nothing is transmitted, which is why it also works on a plane or in a locked-down office network.

    How to use it

    1. Select two or more PDF files, or drag them onto the drop zone.
    2. Check the page count shown for each file.
    3. Reorder with the up and down buttons — files merge top to bottom.
    4. Press Merge, then download the combined PDF.

    Features

    • No upload: files are processed in browser memory
    • Reorder files before merging
    • Page count shown per file and for the result
    • File size total so you can see the result before saving
    • Works offline and on mobile browsers

    Worked examples

    One submission, four documents

    An application requiring a form, ID scan, proof of address and a payslip becomes a single 11-page PDF in the right order, instead of four attachments that a reviewer may open out of sequence.

    Monthly invoices

    Twelve monthly invoices merge into one annual PDF for an accountant. Page order follows the list, so merge oldest to newest for a chronological file.

    Frequently asked questions

    Are my PDFs uploaded to a server?

    No. The merge happens with JavaScript in your browser. The files never leave your device, there is no upload step and no copy is stored anywhere. You can verify this in your browser's network panel.

    Is there a page or file size limit?

    There is no artificial limit. The practical limit is your device's memory, so a phone will struggle with hundreds of pages while a desktop handles them comfortably. Very large scans above roughly 100 MB may fail on older devices.

    Does merging reduce quality?

    No. Merging copies the existing pages into a new document without re-encoding images, so text and images stay identical. If you want a smaller file, compress or downsample the images first, then merge.

    Can I merge password-protected PDFs?

    Not directly. You need to remove the password first with the owner's permission, then merge. This tool cannot bypass encryption, by design.

    Can I split a PDF instead?

    This page merges only. Splitting is a different operation and is not included here rather than shipping a half-working version.
