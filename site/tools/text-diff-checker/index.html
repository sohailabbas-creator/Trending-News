What the Text Diff Checker does

Comparing two versions of a text by eye fails because human attention is drawn to meaning, not to missing words. A single deleted not reverses a sentence while looking almost identical to the original.

This checker uses a longest-common-subsequence comparison — the same family of algorithm as git diff — to mark every added and removed line, count them, and score how similar the two texts are. It can ignore case and whitespace, which is useful when the only real change is formatting, and it works as well on code and configuration files as on prose.

How to use it

  1. Paste the original text in the left box and the revised text in the right.
  2. Press Compare.
  3. Review the highlighted result: removed lines in red, added lines in green, unchanged in grey.
  4. Tick ignore case or ignore whitespace if formatting differences are not relevant.

Features

  • Line-by-line diff with colour highlighting
  • Counts of added, removed and unchanged lines
  • Similarity percentage for a quick sense of scale
  • Ignore case and ignore whitespace options
  • Copy the result as unified diff text

Worked examples

A price change in a policy document

If free shipping moves from orders over 50 to orders over 75, the diff shows one removed line and one added line. Everything else is unchanged, which confirms no other clause was edited.

Whitespace noise

Re-indenting code produces a large red-and-green diff if whitespace counts. Tick ignore whitespace and the true change — one renamed variable — appears on its own.

Frequently asked questions

How does the comparison algorithm work?

It computes the longest common subsequence of lines between the two texts, then marks every line outside that sequence as added or removed. This is the same approach used by git diff and is what produces the familiar plus and minus notation.

What does the similarity percentage mean?

The share of compared lines that are unchanged. A 33% score means roughly two thirds of the lines differ in some way. It is an indicator of scale, not a measure of importance — a single changed word in a one-line contract clause can matter more than 100 changed lines of formatting.

Is my text stored?

No. The comparison runs in your browser and the text disappears when you close or reload the page.

Can I compare code files?

Yes. Any plain text works: JSON, SQL, HTML, CSV, configuration files. Formatting differences count as changes unless you enable the whitespace option.
